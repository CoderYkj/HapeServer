## 1. P0 目标

在**单机、无集群、无跨服**的条件下，验证架构的最小闭环：

1. goakt 接入与 `ActorSystem` 抽象可用，业务 actor 不直接依赖 goakt。
2. 玩家聚合、地图区域、行军/建造定时器能跑通。
3. WAL + 本地快照能在 kill -9 后恢复，状态与模型一致。
4. WorldRankActor 的名次与暴力排序一致，支持重建。
5. 定向交易在崩溃注入下不出现钱货两空、不重复入账。
6. 1k bot 持续 1 小时，p99 < 200 ms，无 OOM、无消息丢失。

## 2. 范围

### 2.1 包含

| 模块 | 内容 |
|---|---|
| Runtime | ActorSystem 抽象、goakt 适配、邮箱/背压、supervisor、虚拟时钟、优雅停机 |
| Timer | 分层时间轮、WAL 持久化、到期路由、恢复重建 |
| Storage | WAL（JetStream）、本地快照（单机，无 RF 复制）、恢复编排 |
| World | PlayerActor（资源/城建/行军/队列/escrow）、RegionActor（tile/预留） |
| Rank | RankKey/RankOrder、跳表、WorldRankActor、重建 |
| Trade | escrow 锁定、Mongo CAS 状态机、TradeService 推进/超时/对账 |
| Gateway | protobuf、会话、简化鉴权（dev token）、bot 客户端 |
| Ops | Prometheus 指标、结构化日志、CI、runbook |

### 2.2 不包含（P1/P2）

- 集群、分片表、etcd 租约、迁移、fencing（P1）。
- RF=3 对等复制（P1）。
- K8s 部署与多区域（P2）。
- 完整 JWT/refresh/踢人（P1；P0 用 dev token）。
- 战斗模拟（P2；P0 只留 `BattleActor` 接口与桩）。
- 赛季结算/重置、跨服组、512 world 压测（P2）。
- 拍卖行（不做）。

## 3. 交付物

1. `cmd/world` 可执行：单机启动，加载快照 + WAL。
2. `cmd/gateway` 可执行：WS 接入，dev token。
3. `cmd/bot` 可执行：N 个 bot，混合场景。
4. 单测、属性测试、混沌脚本、1h soak 报告。
5. 协议文档、运行手册、验收报告。

## 7. 验收用例

### 7.1 功能用例（AC）

| ID | 场景 | 步骤 | 期望 |
|---|---|---|---|
| AC-01 | 登录与持久化 | 创建玩家→执行 10 条指令→重启 | 重启后状态与重启前一致 |
| AC-02 | 指令幂等 | 同一 OpID 发两次 | 资源只扣一次，第二次返回缓存结果 |
| AC-03 | 资源守恒 | 1k 条随机指令 | 资源不为负；产出/消耗守恒 |
| AC-04 | 行军到达 | 派兵 10s 后到达 | 到达误差 <200ms，部队状态正确 |
| AC-05 | 建造队列 | 连排 3 个建造 | 串行完成，扣费只一次 |
| AC-06 | 区域预留 TTL | 预留 tile 不确认，等 30s | 自动释放，其他玩家可占 |
| AC-07 | 排行精确 | 10k 随机玩家，对比暴力排序 | TopK 与 RankOf 全部一致 |
| AC-08 | 排行重建 | kill RankActor→重建 | 重建后名次与重建前一致 |
| AC-09 | 排行乱序/重复 | 重复 version、乱序更新 | 旧事件被丢弃，最终名次正确 |
| AC-10 | 交易成功 | A/B 锁定→结算 | 双方资产精确交换，各扣一次 |
| AC-11 | 交易超时 | B 不确认，等 10min | A 资产全额退回，状态 refunded |
| AC-12 | 交易崩溃（锁定未写文档） | 锁定后 kill -9 | 重启后 10min 内自动退回 |
| AC-13 | 交易部分结算 | A 入账后 kill -9 | 重启后 B 补入账，无重复 |
| AC-14 | 孤儿 escrow | 注入孤儿 escrow | 对账任务发现并退回，指标 +1 |
| AC-15 | WAL 恢复 | 执行 N 条后 kill -9 | 回放到最后一条完整记录，状态一致 |
| AC-16 | 快照损坏 | 翻转最新快照 1 bit | 检测 CRC 失败，回退上一代并告警 |
| AC-17 | 定时器恢复 | 设 1000 个定时器→重启 | 每个只触发一次，时间正确 |
| AC-18 | 背压 | 慢消费者灌满邮箱 | 网关返回 busy，不丢业务消息 |
| AC-19 | 1k bot soak | 1k bot 混合场景 1h | 错误率 <0.1%，p99 <200ms，RSS 稳定 |
| AC-20 | 优雅停机 | 停机时有在途指令 | 已接收指令全部处理或明确失败 |
| AC-21 | 指标与追踪 | 触发各类操作 | 指标有值，MsgID 可串联 |
